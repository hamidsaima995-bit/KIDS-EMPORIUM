# Kids Emporium

An online store demo for a children's clothing shop, with a product catalog, cart, checkout flow, and an admin view. It also hosts the sample site used to show the NexaBot shopping assistant in action.

## Tech

- Node.js with Express
- A static storefront served by the server

## What is inside

- `server.js`, the Express server
- `index.html`, the storefront
- `admin-demo.html`, the admin view

## Running it locally

You need Node.js installed.

```
npm install
npm start
```

The server starts and serves the store. Open the address it prints in your browser.

## Deployment

Deployed on Railway. Pushing to the main branch updates the live demo.
